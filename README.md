## 🔍 Cómo navegar

1. **Ver Código Fuente**: Abre la carpeta `/decompiled/sources`
2. **Ver Recursos**: Abre la carpeta `/decompiled/resources`
3. **Ver Manifest**: Abre `/decompiled/AndroidManifest.xml`
4. **Ver Librerías**: Abre la carpeta `/decompiled/lib`

- **jadx 1.5.0** - Descompilación de código Java/Kotlin
- **GitHub Actions** - Automatización del proceso
